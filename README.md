# Currency Converter

A modern and responsive Currency Converter web application built using React.js and JavaScript. The application allows users to convert currencies in real-time using live exchange rate APIs with a clean and user-friendly interface.

---

## 🚀 Features

- Real-time Currency Conversion
- Live Exchange Rate API Integration
- Convert Between Multiple Currencies
- Responsive User Interface
- Fast and Simple Conversion
- Swap Currency Functionality
- User-Friendly Design

---

## 🧰 Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### API
- Exchange Rate API
